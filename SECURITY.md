# Security and privacy reports

## Gates close

Every temporary permission needs a narrow purpose, an owner, a close step, and
a verified closed state. Every human-facing gate needs an exit. A process that
can only return a person to the same gate is rejected.

This is a public repository. Never put a password, token, private key, recovery
phrase, private conversation, unpublished defense, personal address, or private
family information in an issue, pull request, commit, screenshot, or attachment.

For a suspected public leak, report the file path and category, not the secret
value, to `pseudonym@chuumind.com`. Rotate or revoke exposed credentials through
their real provider. Deleting a Git commit does not make a copied secret private
again.

There is no public hacking challenge, bounty, safe-harbor program, or permission
to test production systems. Do not attack services or people. Security research
requires an explicit scope, lawful authorization, isolation, disclosure rules,
and a funded response process before it opens.
